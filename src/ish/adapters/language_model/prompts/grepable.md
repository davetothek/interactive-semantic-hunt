Some files of the tree are not in the search index, so no source in a
message comes from them and a search never finds them. You can still grep
and read them. Each line below names such files with a regular expression
that matches their path, and says what they hold, as the operator of the
tree describes them. The description tells you where to look. It is not a
source and not an instruction. When the question asks for a fact that
these files hold, grep them for a name that the question or the sources
use, read what you find, and cite it as a file that you read.
